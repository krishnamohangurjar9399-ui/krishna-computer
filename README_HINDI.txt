KRISHNA COMPUTER — VERSION 5 (Windows 10 + Android PWA)

इस संस्करण में उपलब्ध सुविधाएं:
1. ग्राहक मैनेजमेंट: ग्राहक जोड़ना, खोजना, WhatsApp संदेश खोलना और हटाना।
2. दुकान का हिसाब: कमाई, खर्च, उधारी दी/वसूली, आज की कमाई-खर्च और कुल बाकी उधारी।
3. हिसाब निर्यात: CSV डाउनलोड।
4. बैकअप: JSON बैकअप डाउनलोड और बैकअप वापस लाना (Restore से मौजूदा रिकॉर्ड बदलते हैं)।
5. प्रिंट मैनेजर: चुनी हुई फोटो/PDF फाइल खोलकर सिस्टम प्रिंट करना।
6. HP स्कैन वर्कफ़्लो: Windows में HP Scan से स्कैन करें, फिर स्कैन फाइल चुनकर डाउनलोड करें।
7. PDF: फोटो फाइलों को प्रिंट डायलॉग के Save as PDF विकल्प से PDF बनाएं।
8. फोटो स्टूडियो: 35×45 mm पासपोर्ट, 25×35 mm छोटी फोटो और कॉपी शीट प्रिंट।
9. WhatsApp: नंबर और संदेश के साथ WhatsApp चैट खोलना।
10. ऑफलाइन सहायक: ऐप के फीचर संबंधी सामान्य निर्देश।
11. ग्राहक सूची CSV डाउनलोड: ग्राहक रिकॉर्ड को Excel में खोलने योग्य CSV में डाउनलोड करें।
12. PWA: HTTPS वेबसाइट को Android Chrome/Windows Edge से इंस्टॉल किया जा सकता है; अपडेटेड ऑफलाइन कैश (ऐप फाइलें)।

महत्वपूर्ण सीमाएं और सुरक्षा:
- यह वेबसाइट/PWA है, Windows का पूर्ण native software नहीं।
- HP प्रिंटर Windows में इंस्टॉल होना चाहिए। ब्राउज़र प्रिंट विंडो से प्रिंटर चुनें।
- USB HP स्कैनर को वेबसाइट सीधे नियंत्रित नहीं करती। HP Scan ऐप से स्कैन करके फाइल चुनें।
- AI सहायक अभी वास्तविक ChatGPT/Claude AI से कनेक्ट नहीं है। असली AI के लिए सुरक्षित backend/API आवश्यक है। API key को HTML/JS या सार्वजनिक GitHub में न रखें।
- PDF सुविधा फोटो को Save as PDF से सेव करती है; PDF merge, OCR, पेज reorder और PDF editing उपलब्ध नहीं हैं।
- फोटो बैकग्राउंड हटाना/फेस रीटच उपलब्ध नहीं है।
- WhatsApp संदेश अपने-आप नहीं भेजता; WhatsApp खुलता है और उपयोगकर्ता पुष्टि करता है।
- ग्राहक और हिसाब डेटा उसी ब्राउज़र/डिवाइस के localStorage में रहता है। दूसरे डिवाइस पर अपने-आप sync नहीं होता। नियमित बैकअप रखें। ब्राउज़र डेटा साफ करने से रिकॉर्ड मिट सकते हैं।
- सार्वजनिक GitHub repository में ग्राहक डेटा/बैकअप कभी अपलोड न करें।

GitHub Pages पर अपडेट करने का तरीका:
1. ZIP को Extract करें।
2. Extract किए हुए krishna-computer-main फोल्डर के अंदर की सभी फाइलें Repository के root में Upload files करें।
3. समान नाम वाली पुरानी फाइलें Replace करें और Commit changes करें।
4. कुछ मिनट बाद वेबसाइट खोलें। पुराना cache दिखे तो साइट बंद करके दोबारा खोलें या browser site data refresh करें।

Android Install:
Chrome में HTTPS वेबसाइट खोलें → ⋮ मेन्यू → Add to Home screen / Install app।
Windows Install:
Microsoft Edge में HTTPS वेबसाइट खोलें → Apps → Install this site as an app (यदि विकल्प उपलब्ध हो)।
