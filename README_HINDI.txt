KRISHNA COMPUTER – पहला वर्किंग वर्जन
======================================

इस ZIP में क्या है?
- index.html : ऐप का मुख्य पेज
- style.css : मोबाइल/कंप्यूटर डिजाइन
- app.js : ग्राहक, हिसाब, प्रिंट, PDF, फोटो, WhatsApp और शुरुआती सहायक
- manifest.webmanifest और sw.js : PWA इंस्टॉल/ऑफलाइन सपोर्ट

चलाने का तरीका:
1. ZIP को Windows 10 कंप्यूटर में Extract करें।
2. index.html पर डबल-क्लिक करके Chrome या Edge में खोलें।
3. Android में इसे इस्तेमाल करने के लिए इस फोल्डर को HTTPS वेबसाइट पर होस्ट करें, फिर Chrome में वेबसाइट खोलकर
   मेन्यू > Add to Home screen / Install app चुनें।
4. दोनों डिवाइसों में एक ही डेटा चाहिए तो अगले चरण में सुरक्षित ऑनलाइन सिंक/लॉगिन सर्वर जोड़ना होगा।

महत्वपूर्ण सीमाएं:
- डेटा फिलहाल उसी ब्राउज़र/डिवाइस के Local Storage में रहता है। ब्राउज़र डेटा साफ करने से रिकॉर्ड मिट सकते हैं।
  ऊपर “डेटा बैकअप” से JSON बैकअप नियमित डाउनलोड करें।
- HP प्रिंटर: Windows में HP ड्राइवर इंस्टॉल करके प्रिंटर को डिफॉल्ट रखें। प्रिंट बटन ब्राउज़र का प्रिंट डायलॉग खोलता है।
- HP स्कैनर: Windows में HP Scan ऐप से स्कैन करें और बनी PDF/इमेज फाइल ऐप में चुनें। सीधे स्कैनर हार्डवेयर नियंत्रण इस MVP में नहीं है।
- PDF टूल फोटो से PDF सेव करने के लिए प्रिंट डायलॉग में “Save as PDF” का उपयोग करता है।
- फोटो स्टूडियो में बेसिक फोटो प्रीव्यू और प्रिंट शीट है; बैकग्राउंड हटाना/फेस रीटच अभी नहीं है।
- AI सहायक अभी ऑफलाइन नियम-आधारित शुरुआती सहायक है। Claude जैसे असली AI के लिए सुरक्षित backend/API integration जरूरी है।
- WhatsApp बटन संदेश तैयार करके WhatsApp खोलता है; अंतिम Send ग्राहक/ऑपरेटर करेगा।

अगला विकास चरण:
1. लॉगिन और क्लाउड बैकअप/मोबाइल-कंप्यूटर डेटा सिंक
2. Claude AI को सुरक्षित सर्वर के माध्यम से जोड़ना
3. स्कैनिंग और PDF merge/compress के उन्नत फीचर
4. फोटो क्रॉप, बैकग्राउंड हटाना और पासपोर्ट शीट
5. बिल/रसीद और ग्राहक उधारी रिपोर्ट

यह शुरुआती MVP है, पूर्ण व्यवसायिक/सुरक्षा ऑडिट वाला अंतिम सॉफ्टवेयर नहीं।
